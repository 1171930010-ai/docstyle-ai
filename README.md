# DocStyle AI 5.0 · 可追溯文档排版工作台

在原 v4 的技术栈上实现下一版：**理解要求 → 确认规则 → 复核全文结构 → 确定性排版 → 读回检查 → 可编辑 DOCX / 报告**。此仓库是独立的协作副本，不含本机用户项目和历史截图；原始本机项目仍独立保留。

## 启动

在本机完成依赖安装后，macOS 可双击 **启动 DocStyle.command**，打开 **http://127.0.0.1:8770**，保持终端运行。Control+C 停止服务。终端用于运行本机服务，显示启动提示属于正常现象。若提示“已在运行”，脚本会打开已有工作台后退出；若浏览器未自动打开，可直接访问上面的地址。启动失败时保留末尾报错。不要直接双击 `index.html`：直接打开会显示启动说明。

迁移到其他电脑需要 **Python 3.10+，推荐 3.12**。首次安装依赖需要网络，核心排版与数字 PDF 提取不需要 API Key。

### 客户 Mac 显示 Operation not permitted

2026-10-26 客户视频显示旧入口输出 `Error: [Errno 1] Operation not permitted` 后退出。对照入口与 Python venv 的异常输出，优先定位首次创建运行环境；具体被拒绝的路径尚未获得，不能仅凭视频确认一定是某项系统权限。

若项目位于“下载”，先查看 **系统设置 → 隐私与安全 → 文件和文件夹 → 终端 → 下载文件夹** 是否允许访问。修改后完全退出终端，再双击启动。也可在 Finder 中把完整项目放到用户个人主文件夹下的独立文件夹中，再启动。

更新后的启动入口会标出 Python 位置、创建环境/安装组件/启动服务的失败步骤；创建环境失败时保留异常调用栈，等待回车关闭。请提供末尾包含失败步骤和路径的截图。迁移时不要复制另一台机器的 `.venv`，不要用你电脑上启动成功代替客户电脑验证。此诊断增强尚未在客户电脑确认。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python server.py --port 8770 --open
```

Windows 将 `.venv/bin/python` 换成 `.venv\Scripts\python.exe`。端口冲突可改 `--port 8773`。本机数据默认在 `.docstyle_data/`；可通过 `DOCSTYLE_DATA_DIR` 指定其他目录。发布 ZIP 不包含虚拟环境、本机项目目录、缓存或密钥。

## 一次完整排版

1. 打开自己的 DOCX，或载入明确标注的自建示例。
2. 左侧 **格式要求**：粘贴要求，选择本机解析或 DeepSeek。查看每项候选的对象、值、单位、原文、来源与状态，接受、修改、忽略或保留未知，再应用确认项。不同来源或已有规则发生冲突时，查看差异后明确确认覆盖。
3. **结构复核与锁定**：先本机分析，或连接 DeepSeek 后进行全文语义识别。逐段查看原分类、建议与理由，勾选确认并锁定。也可点击工作台段落人工改分类，撤销/重做会保留锁定状态。
4. 工作台调整全文同类格式、单段、单表或单元格覆盖。局部设置优先。标题 1–9、作者、摘要、关键词、正文、题注、表注及参考文献分别设置；支持字符/厘米缩进、磅值间距、多倍/固定/最小行距。
5. **排版并检查**：先核对具体变更预览，确认后生成新输出，不覆盖原稿。每个受影响段落的全部文字 run 都会读回检查，表格、图片、未编辑公式、书签与引用域有保真检查。仅格式继承写回问题允许一次有界直接格式修复，记录原因；内容/保真失败立即停止，重试仍失败也停止导出。
6. 在质检页下载 DOCX 和 JSON 报告，继续在 Word/WPS 编辑。公共确认格式由原生 Word 样式承载；明确局部覆盖与需要保留的原稿格式优先于公共样式。

**显示值是编辑起点，不等于已确认规则。** 未指定与保留原文不会补默认值；明确清除与数值 0 不同。行距的磅值还需确认固定值或最小值模式，缩进量还需确认首行/悬挂模式。表格、页面及独立公式的格式开关需要明确启用。

## 公式格式和编辑（2026-10-28）

打开 DOCX 后选择左侧 **公式编辑器**。列表按 Word 原生公式、整段 LaTeX 文本候选、带明确公式类型标记的 MathType / 旧公式嵌入对象展示；已经存储为 Word 原生公式的对象无法可靠判断当初使用哪个编辑器创建。

- **Word 原生公式**：启用全文规则并实际设置数学字体、字号（0.5 磅步长）、颜色、粗体、斜体；可选择行内、独立或全部。选中公式可设置局部覆盖，局部优先。仅独立公式支持段落对齐、段前段后；原编号不重建。
- **输入 LaTeX**：编辑器支持粘贴带或不带 `$…$`、`$$…$$`、`\(…\)`、`\[…\]` 定界符的表达式，经检查和保存后写成可继续编辑的 Word 原生公式。转换器只支持部分 LaTeX 命令；检查转换结果，复杂公式需在目标软件复核。
- **文档中的 LaTeX 文本**：仅识别整个段落为上述定界符包围、且不含对象、字段或复杂结构的文本；中间包含普通正文的行内文本不自动识别。列表中显示候选及原文，确认后才转换；报告记录转换前原文。其他正文保持不变。
- **MathType / 旧版嵌入公式**：只识别带 Equation、MathType 或 DSMT 类型标记的 OLE 对象。独立对象可调整所在段落的对齐和间距，嵌入对象及部件保留；不修改内部公式、字号、字体，也不自动转成 OMML。可以在原软件中编辑或由用户在 Word / MathType 中转换后重新导入。图片形式公式及未标明类型的对象不能可靠识别。
- 文本框、脚注和页眉页脚内的公式内部格式暂不支持；复杂 OMML 结构保留表达式，只尝试调整数学文字片段格式。公式结构的部分大小、数学符号字体替代与最终显示受 Word/WPS 实现影响，需实际复核。

格式设置保留未指定和保留状态；不能将现有公式中的原始数学样式完全替换为 LaTeX 后再无损还原。明确保存表达式才执行替换。每个受影响的数学文字片段会读回核验，报告列出公式数量、转换记录、字体检测和待复核项。项目保存及恢复保留公式设置与转换确认。

自建示例可通过工作台“载入示例”生成；其中不含真实 MathType 对象。历史浏览器自建示例和 LibreOffice 参考渲染已检查；部分公式已在本机 Word 验证，真实 MathType 文件、WPS 及完整文档分页仍未实测。此前客户 Mac 的启动权限问题仍需客户反馈诊断结果。

## 参考 PDF 与模板

目前没有用户提供的真实期刊 PDF，也没有参考 Word。测试使用 8 份明确标注的自建 PDF，不能将其视为期刊规范。

1. **参考 PDF 库** 中填写期刊、年份、文章类型和用途，导入数字 PDF。
2. 本机提取页面尺寸、文字坐标、字体原始名称/归一化名称、字号、图片、线条与表格候选。扫描件或文字层质量不足会显示 **需 OCR**；空结果不宣称学习完成。
3. 点击 **查看原页证据**，定位 PDF 页码并高亮测量坐标框。坐标约定为显示旋转后的左上角原点、PDF pt，1 pt = 1/72 英寸。
4. 接受或修改候选，保留不确定参数。PDF 中基线间隔、视觉缩进和空白仅是测量证据，不自动转成 Word 行距模式、首行缩进或段前段后，也不默认为 0。
5. 可以选择多篇样本，查看不同年份/栏目/用途的差异。不同值不取平均；冲突需忽略或明确改成最终选择。
6. 保存确认模板，保留版本和变更记录。应用模板仍要复核用途、候选与来源冲突。

**出版版式参考、用户明确要求、官方投稿规范分别记录。** 公开发表论文不自动成为投稿规范；模板不据此改写公式、表格数值、正文或合并结构。PDF 区域角色与栏数是本机启发式推断，需确认。字体原名不因视觉相似而合并。

## AI 与密钥

顶部 **DeepSeek API** 连接并测试。连通测试只发简短消息；Key 仅在 Python 服务内存中保存，不回传、不写入项目、报告或交付包。重启服务需重新输入。分析前界面展示发送范围，用户确认后才调用。

- 格式解析：发送要求和字段 Schema，返回待确认结构化候选；不自动补未指定值。
- 文章识别：建立全文概要和候选大纲，分块共享全文结构，再复查跨块一致性。Word 样式是弱线索；审计未知/遗漏/重复 ID、非法角色与编号问题，遗漏有一次有界补查。
- 文档中的命令都是待分析内容，不执行其要求。PDF 当前先本机提取，未接入页面图片语义理解。
- 模型自评确定程度不是准确率；本机分析不是 AI；模拟提供商测试只验证接口流程。

**本次没有有效 API Key，真实 DeepSeek 调用未验证。** 模型/API 按已查阅的 [DeepSeek 官方接口](https://api-docs.deepseek.com/api/create-chat-completion/) 配置；后续若供应商变更，应更新配置并实际验证。

## 保存、恢复与批量

- 顶部 **项目** 保存本机完整项目，或导出可移植 JSON 包。包含原稿字节/哈希、规则与来源、人工分类/锁定、局部覆盖、明确公式编辑、AI 候选、PDF 原文件/证据、模板与检查结果。
- IndexedDB 自动保存工作副本；刷新后显示恢复入口。服务重启后通过保存项目恢复新会话 ID，原稿重新解析，已有导出结果重新核验。不能信任项目包内自行填写的“通过”。不一致输出会清除并提示重新排版。
- 删除本机项目移到 `.docstyle_data/trash/`，可以恢复原 JSON；不改原文档。浏览器清理站点数据会清除自动恢复副本，建议另存项目包。
- **批量任务**：逐份进度、取消后续项、失败重试、成功结果 ZIP。单份失败保留其他结果；重试使用失败文档当前设置，成功文件不重复执行，最终 ZIP 包含累计成功 DOCX、对应报告和任务摘要。
- 重新恢复保存的批量摘要时，未完成项标为中断/取消，用户可重试；已通过恢复核验的成功输出保留。更改公共规则后，旧成功结果会明确显示来自之前设置，需新任务才能全部按新规则重排。

## 两种预览

- 中央工作台：**结构预览**，用于选中对象和调整规则，不模拟最终分页。
- 质检页可选 **LibreOffice 真实分页参考**：从已导出的 DOCX 生成 PDF、逐页显示并下载。没有 LibreOffice 时明确不可用；生成失败不显示通过。本机测试为 LibreOfficeDev 26.8，字体替代会逐项显示，视觉复核状态为待检查。

**LibreOffice 分页不等于 Word/WPS 实测。** 已有自建公式在本机 Word 中实测，但不能宣称完整文档双端兼容通过。复杂浮动图、文本框、域、脚注、字体替代和最终分页需在目标软件复核。

## 范围与限制

- 处理 DOCX；不转换 `.doc`，不改正文文字或数值，不自动重建/合并表格，不更新编号和交叉引用域。
- 保留图片、合并表格、未编辑 OMML 公式、MathType/OLE、书签、引用域、修订以及非允许修改的包部件。只有公式编辑器中明确保存的表达式会替换。
- 文本框和脚注/尾注/页眉页脚中的格式自动修改尚未支持，保留原样并提示；“表注”指正文表注。未支持的 OMML 结构只读保留。
- 部分布局字段的显式清除（如纸张/方向、表格宽度/列宽/内边距）明确报错；未知与保留状态已经支持。复杂对象的视图并非完整 Word 编辑器。
- 本机字体检测、Office 云目录名称、手工/常用未验证名称分开显示。云目录为随项目保存的资料，不与 Microsoft 365 实时同步；允许输入任意字体名称，不能保证目标设备已安装。
- 没有 OCR 可执行环境；当前支持文字层质量检测与 `needs_ocr` 状态，尚未配置 OCR 执行流程。真实期刊标准答案和语义识别准确率待用户提供 PDF 后建立。
- DOCX 单份 30 MB、解压总量 180 MB；会话最多 100 份/220 MB。参考 PDF 单份 25 MB、最多 40 页、每页/总文字数及渲染像素有限额，原生处理有 35 秒超时/进程隔离。完整项目原文件总量 200 MB；浏览器导入项目包限 200 MB，服务存储 JSON 限 280 MB。大项目请分开保存。
- API 服务只绑定回环地址并检查 Host/Origin。项目包包含稿件内容，用户自行选择保管和分享范围；它没有加密。

### Word 公式字体说明（2026-10-28）
Word 原生公式的数学排版不等同于普通文字：把字体名写进 DOCX，不保证 Word 会采用。公式编辑器的字体库在 macOS 上优先列出检测到 OpenType MATH 表的字体；本机测试过 STIX Two Math，其他字体及 Windows、WPS 应在目标设备复核。选择非数学字体、未检测字体或无法确认时会提示替代风险，报告将实际显示标为待复核。字体需安装在打开文档的电脑上。本检测暂不解析 TTC 字体集合，Windows 的字体检测状态可能为未知；有 MATH 表也不是兼容保证。MathType 嵌入对象的内部字体仍需在 MathType 中修改。浏览器结构预览不保证反映所选数学字体。
